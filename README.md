# GroceryMart Backend

Backend API for GroceryMart ecommerce application.

## Features

- User Authentication
- Product Management
- Cart System
- Order Management
- Razorpay Payment Integration
- Admin Dashboard
- MongoDB Database

## Tech Stack

- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- Razorpay

## Run Locally

```bash
npm install
npm run server
```

## Environment Variables

Create `.env` file:

```env
MONGO_URI=
JWT_SECRET=
RAZORPAY_KEY_ID=
RAZORPAY_KEY_SECRET=
```
